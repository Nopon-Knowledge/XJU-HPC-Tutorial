# 常用命令

## 配置清华 PyPI 镜像

```bash
python -m pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
python -m pip config get global.index-url
```

## 安装项目依赖

```bash
python -m pip install -r requirements.txt
python -m pip check
```

## 查询队列和节点

```bash
jqueues -u "$USER"
jhosts
```

## 提交 GPU 检测作业

```bash
mkdir -p "$HOME/logs"

jsub -q gpu -J nvidia-smi-check \
  -cwd "$HOME" \
  -o "$HOME/logs/nvidia-smi.%J.out" \
  -e "$HOME/logs/nvidia-smi.%J.err" \
  -n 1 -M 1024 \
  -gpgpu 1 \
  nvidia-smi
```

## 提交 PyTorch CUDA 检测作业

```bash
PYTHON="$HOME/venvs/dl-py310-cu121/bin/python"
CHECK_CODE='import torch; print("PyTorch:", torch.__version__); print("CUDA:", torch.version.cuda); print("Available:", torch.cuda.is_available()); assert torch.cuda.is_available()'

jsub -q gpu -J pytorch-check \
  -cwd "$HOME" \
  -o "$HOME/logs/pytorch-check.%J.out" \
  -e "$HOME/logs/pytorch-check.%J.err" \
  -n 2 -M 8192 \
  -gpgpu 1 \
  "$PYTHON" -c "$CHECK_CODE"
```
